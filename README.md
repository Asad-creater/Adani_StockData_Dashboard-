# Adani_StockData_Dashboard-
Stock Market Data Analysis Dashboard using Power BI , SQL and Python.
Stock Market Data Analytics Dashboard:

Developed an interactive Stock Market Data Analysis Dashboard using Power BI for visual analytics and insights.
Performed data extraction, transformation, and querying using SQL to ensure accurate and structured datasets.
Utilized Python libraries (Pandas, NumPy) for data cleaning, filtering, and preprocessing.
Analyzed key stock indicators including Open, Close, Volume, and 52-Week High/Low trends.
Implemented dynamic filters (Day, Month, Quarter, Year) for detailed time-based analysis.
Delivered actionable insights through KPIs, trend analysis, and comparative visualizations to support data-driven decisions.
